# 📝 Student To-Do List

A beginner-friendly student project built with **HTML, CSS, and JavaScript**. It helps students organize study tasks and keep track of completed work.

## ✨ Features
- Add tasks and delete individual tasks
- Mark tasks as completed or pending
- Filter tasks by All, Pending, and Completed
- Clear all completed tasks in one click
- Automatically save tasks in the browser using Local Storage
- Responsive layout for mobile and desktop
- Accessible labels and helpful empty-state messages

## 🚀 How to Run
1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Enter a task such as `Study Python loops`.
4. Click **Add Task** and use the checkboxes and filters to manage your tasks.

No installation or external libraries are required.

## 🧰 Technologies
- HTML5 — page structure
- CSS3 — responsive design and styling
- JavaScript — task operations and filtering
- Local Storage — saves tasks in the current browser

## 📚 Student Project Report
**Introduction:** The To-Do List is a simple productivity application for students.

**Objective:** Make it easier to record daily assignments, study plans, and reminders.

**Advantages:** Easy to use, responsive, and works without a backend after loading.

**Disadvantages / Limitations:** Tasks are stored only in the current browser and are not synced between devices.

**Comparison:** Unlike a paper checklist, this app lets users mark tasks complete, filter pending work, and automatically save tasks in the browser.

**Conclusion:** This project demonstrates DOM manipulation, event handling, arrays, and browser Local Storage.
